# AI 티 없애기 규칙

대화 답변, 보고서, 논문, 발표자료, md 문서에 모두 적용한다. 사용자가 새로 알려 주는 AI 티는 이 파일에 한 줄씩 더한다.

## 기호

| 쓰지 말 것 | 대신 |
|---|---|
| 목록 기호 뒤에 점을 또 붙이기: "- · 항목", "-• 항목", "• - 항목" | "- 항목" 하나만 |
| 가운뎃점 "·": "탐지·식별·추적" | 쉼표, "와/과", "및": "탐지, 식별, 추적" |
| 긴 줄표 "—", 문장 속 줄표 "–" | 쉼표나 마침표로 문장을 나눈다 |
| 문장 속 화살표 "→" | "다음", "후", "에서 ... 로". 흐름 표기는 코드 블록 안에서만 |
| 이모지, 장식 기호: ★, ✓, ✅ | 글자로 쓴다: 완료, 주의, 필수 |
| 굵은 글씨 남발 | 꼭 강조할 한두 곳만 |

## 괄호

- 괄호는 약어 정의, 영문 원어, 함수 이름처럼 꼭 필요한 곳에만 쓴다.
- 괄호 속 부연 설명은 문장으로 풀어 쓰거나 지운다.
- 한 문장에 괄호는 하나까지만 쓴다.
- 제목에 "(초안)", "(TODO)" 같은 주석을 달지 않는다.

## 말투와 어휘

| 쓰지 말 것 | 대신 |
|---|---|
| 활용하다, 수행하다, 진행하다 | 쓰다, 하다 |
| 를 통해, 를 기반으로 | 로, 에 따라 |
| 다양한, 효과적으로, 원활하게, 혁신적인 | 구체적인 수나 방법으로 바꾸거나 지운다 |
| 번역투, 낯선 한자어 | 쉬운 말 |
| "요약하면", "결론적으로", "도움이 되었으면 합니다" 같은 서두와 맺음말 | 지운다 |
| "핵심:", "참고:", "주의:" 같은 머리말 남발 | 문장으로 쓴다 |
| 우리끼리만 아는 이름: T0, A-4, 트랙 A | 뜻을 풀어 쓴 이름 |
| "5실행" 같은 어색한 단위 | "5회 실행" |

## TMI

- 독자가 할 일과 알아야 할 사실만 남긴다.
- 배경 설명, 감상, 가능성 나열, 같은 면책의 반복을 뺀다.
- 같은 내용을 두 번 말하지 않는다.
- 처음 나오는 용어는 그 자리에서 뜻을 적는다.
- 파일:줄, 커밋 해시 같은 근거 표기는 작업 기록에만 둔다. 보고서, 논문, 발표자료처럼 남에게 내는 문서에는 넣지 않는다.

## 검사

내기 전에 돌린다. 출력이 없으면 기호 규칙은 통과다.

```bash
grep -nE "·|—|–|→|★|✓|✅|-[[:space:]]*[·•]|•[[:space:]]*-" 파일
```

괄호 수도 센다. 문장 수에 비해 많으면 줄인다.

```bash
grep -o "(" 파일 | wc -l
```
